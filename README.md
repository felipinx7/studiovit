# STUDIO VIT - PORTIFÓLIO 

Website desenvolvido para uma agência de design com o objetivo de apresentar de forma clara, moderna e atrativa todos os serviços oferecidos, fortalecendo a presença digital e facilitando o contato com novos clientes.

## Visualização do projeto

![Visualização do projeto](https://github.com/user-attachments/assets/587f9b37-34c5-4e89-8093-795a35117419)

# Funcionalidades
- Apresentação institucional da agência
- Listagem de serviços oferecidos
- Seção de portfólio com projetos realizados
- Layout totalmente responsivo

# Destaques Técnicos

- Código organizado e escalável
- Componentização reutilizável
- Boas práticas de responsividade
- Foco em performance e carregamento rápido
